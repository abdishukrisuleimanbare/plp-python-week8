
# PLP Week 8 Final Project: Personal Mini-Toolkit

## Project Overview

The Personal Mini-Toolkit is a Python command-line
application developed as the final project for the
Power Learn Project (PLP) Software Engineering course.

It combines Python programming concepts including
variables, input and output, conditionals, loops,
lists and functions.

## Features

### 1. Number Guessing Game
Allows users to guess a secret number between 1 and 10.
The program provides hints until the correct number is found.

### 2. To-Do List Manager
Allows users to add, view and remove tasks.
Python lists are used to manage tasks while the program runs.

### 3. Simple Calculator
Performs addition, subtraction, multiplication and division.
It also handles invalid inputs and division by zero.

## Project Files

- toolkit.py - Main Python application.
- toolkit_plan.txt - Project planning and design.
- screenshots/ - Screenshots showing the program and tools.

## Requirements

- Python 3 installed.
- Visual Studio Code or another Python editor.
- A terminal or command prompt.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

```bash
python toolkit.py
```

5. Select a tool from the displayed menu.
6. Follow the instructions displayed by the program.

## Learning Reflection

Building this project helped me bring together the
Python concepts I learned throughout the PLP course.

The hardest part was designing the menu loop so that
the program returns to the main menu after each tool.

The bug that took the longest to fix was handling
invalid user input without interrupting the program.

I learned how Python lists can store and update tasks
while an application is running.

I also improved my understanding of loops, conditionals,
functions and user input validation.

If I had one more week, I would add a file-saving feature
to ensure that my to-do list remains available after
the program closes.
